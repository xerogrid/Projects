# Audio Files

Short vocoder clips for the IG-12 assassin droid DFPlayer Mini. Copy these
onto the player's microSD card using the naming and folder layout expected by
`Droid-Foundry/Assassin Droid/FinalVersionLondon.cpp`.

| File | Role |
| --- | --- |
| `BCvocoderstartup.mp3` | Boot / startup |
| `BCVocoderHelloorganic.mp3` | Hello |
| `BCVocoderGreetings.mp3` | Greetings |
| `BCVocoderSystemError.mp3` | Fault / error |

These are original project assets. They are small enough to live in Git; do
not add longer show tracks or raw session dumps here.
