# Digital Signage Appliance

Dedicated project directory for the Digital Signage Appliance.

This project is independent of the BambuLabs VLC and Stream Deck work.

## Status

The project has been created. Product requirements and the implementation
architecture have not yet been defined.

## Decisions needed next

1. Define the appliance's purpose, audience, and content to display.
2. Record the target screen resolution, orientation, and display hardware.
3. Choose the appliance hardware and operating system.
4. Define content management, scheduling, and update workflows.
5. Define network requirements and expected offline behavior.
6. Specify unattended startup, health monitoring, and failure recovery.
7. Establish deployment, administration, and security requirements.
8. Write acceptance criteria for the first usable version.
